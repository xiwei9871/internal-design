## 与前轮的实质差异

V3 将旧示意坐垫 / 背垫的 60–90 mm 间隙当作真实尺寸，并漏掉 OBJ 对象旋转造成轴向错误。V4 的整件坐包缝实测 7.5 / 10.0 mm，背包约 8.0 mm；座包与木承托一起建模。软包用 Blender 官方闭合 cloth pressure 方法建立有缝边的静态原型，逐帧实际评价了形变，未称泡棉 / 羽绒力学模拟或动画烘焙认证。

旧 `03_EXISTING_CEILING` 集合的渲染 / 视口隐藏导致环境光从缺失顶面进入。V4 恢复原集合及 View Layer 显示，顶板网格未改；两处向上射线均命中 z=2.8 m 的 `CEILING_LOWER`，在闭合室内重新进行 lookdev。此结果已记录到专用 ArchViz 技能经验。
