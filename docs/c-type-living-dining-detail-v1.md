# 客厅与餐厅精细 Blender 模型合同

业主于 2026-10-09 同意开始建模。浅原木、米白、简洁、明亮是全屋方向。

- 基础：SUNROOM_STEPPED_STORAGE_V1.blend 的独立派生版本；建筑、开口、标高和其他房间几何保持不变。
- 客厅：A Faithful 主体家具；B Designer VIEW_01 的地毯、浅亚麻窗帘、东墙长低柜上方抽象画。无 Creative 元素，不默认添加落地灯、搭毯、额外摆件。
- 餐厅：1600×800 mm 跑道形餐桌，台面 750 mm，保留四把椅子的位置与包络；浅色圆润吊灯，可擦洗外壳，具体商品型号尚未确认；不挂画。
- 效果图仅约束外观；真实模型约束尺寸。茶几保留 1000×550×400 mm。
- 制作：几何和结构→低成本多角度检查→PBR 材质与光泽→中性日光和真实灯具→实际 Cycles 渲染→重新打开验证。
- 交付：可编辑、打包贴图的独立 .blend、可复现 Python、客厅和餐厅主视角及近景、尺寸与源几何审计、评审网页。
- 本轮是可视化精细候选，不作为家具生产图；吊灯 SKU、织物商品和现场施工细节待后续选择。
- 现有北阳台阶梯柜继承为候选，尚未把静态身高差升级为动态防碰头结论。

画作与地毯使用代码绘制的原创近似图案，不声称与参考照片中商品相同。家具构造参照业主木甲木乙白蜡木图册与现有模型，并保留准确包络。
