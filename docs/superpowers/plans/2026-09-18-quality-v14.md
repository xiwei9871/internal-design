# A14 设计出图改进实施计划

> 执行：使用 executing-plans / subagent-driven-development 逐项实现。用户已于 2026-09-18 批准研究报告的方案与顺序，无需重复设计确认。

**目标：** 保留已确认布局和旧版成果，统一几何与语义，修正 CAD，制作可打印图纸及同模高质量渲染，建立可复建和可核验的交付。

**架构：** `design/approved_v14.json` 保存 A7 来源、稳定 ID、已确认修正和明确的待核实参数；`design_model.py` 为 FreeCAD/Blender/CAD 共用读取与坐标转换层。旧输出不覆盖，新输出归档到 `deliverables/v14` 与 `scheme_a_v14`。

**技术栈：** Python unittest、ezdxf、FreeCAD、Blender Cycles、Pillow/scipy；延用 .venv，避免无关依赖升级。

- [x] 1. 数据与回归：先编写低柜高度、次卫门型、服务墙尺寸链、稳定 ID、坐标变换的失败用例，再建立共享模型与 provenance；已确认设计值与现场未知值分别记录。
- [x] 2. CAD 正确性：复现并修复 elem/band 的 y+h、注册线型、分开结构顶与吊顶、门扇/洞宽；消费者读取共享数据。测试正负偏移及全部 DXF audit errors/fixes=0。
- [x] 3. CAD 样板：纸空间毫米图框、固定视口比例、黑白 PDF、纸面字高、家具符号、内外尺寸；优先 A101 与服务墙，扩展为十张图；现场与产品未知值继续标注。
- [x] 4. 三维：更新 FreeCAD 消费共享模型并输出 A14 CAD；Blender 从同版对象重建材质/家具/服务墙，不使用 AI 作为结构依据；检查相机、对象包络与落地。
- [x] 5. 渲染：先厨房/主卧预览，视觉核验后渲七视角；保留主图、结构/深度/法线/对象遮罩；物理渲染优先，AI 可选局部合成且不自动替换批准版本。可选接口 HTTP 400，无有效 AI 候选。
- [x] 6. QC 与发布：统一评估画幅、双向结构误差、空边缘处理、与在版比较、hash manifest；生成浏览页与状态表，核验实际输出。
- [x] 7. 独立审查：先需求覆盖，再代码/数据质量；修复重要问题，运行完整测试与导出检查，附已完成/待确认清单。

验收：不覆盖 A12/A13 与原 DXF；关键对象跨模型一致；导出 DXF audit 无错误及自动修复；新图纸有实际纸空间视口；每个新视角使用固定相机和相同版本几何；交付清楚标明尺寸依据、设计假设和人工验收状态，不把 AI 排名当批准。

实施偏差与补充：主卫 A11 机位距打开的门扇过近，实际射线证实中心 28mm 处被挡。A14 改到 `(360,825)`，目标/焦距不变；添加 9 射线近遮挡检查，旧点能复现失败，新点通过。主卫展示改为并列对照，其余六张拖动比较。厨房窗台/台面高差及北窗边界冲突保持显式待复尺，不擅自改源图。
