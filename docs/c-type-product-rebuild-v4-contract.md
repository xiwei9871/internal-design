# 客厅与餐厅整件重建测试 V4

业主 2026-10-10 授权按实物优先流程重建客厅与餐厅，尽可能复现已选效果图。客厅 A 家具 / B 地毯、窗帘和东墙画；餐厅跑道桌及浅色圆润吊灯，无挂画。真实建筑、空间关系、沙发最大占地 1800×3300 mm、茶几 1000×550×400 mm、低柜包络、躺椅包络、餐桌 1600×800×750 mm保持。旧内部坐垫间隙不作为实物尺寸。

## 对象原型与选择

- 沙发：整件定制白蜡木 / 麻棉 L 型候选，依据图册 PDF 第 4 页木框家族与第 8 页白蜡木软包条目的材料 / 构造和 A 主图共同建立。它不是任何原厂 SKU 的缩放副本。重建整个木框、腿、承托、座面、连续软包、背部 / 扶手；不复用 Fly 的坐垫网格，不拼原木框和别款软包，不添加装饰抱枕。
- 躺椅：按图册木框休闲家具的连接 / 支撑和 A 主图的斜背软包做整件定制候选。原位置与 1700×900×800 mm 最大范围保持；后背真实支撑、坐垫压在座架上、软包缝边和侧扶手一起评审。
- 茶几与低柜：实际图册 PDF 第 11 页长几、13 页电视柜的板材 / 框腿 / 连接是构造参考，按本户已选 A 外观和真实尺寸做定制双层茶几 / 开放低柜，不能写成图册原厂同款。
- 餐桌：C 主图双支撑跑道桌 + PDF 第 11 页 1119 双柱长几的实物支撑语言作为构造依据，本户定制 1600×800、标高 750，桌板、承托横梁、双柱与重力落地一致；原柱尺寸不是冻结事实。
- 餐椅：C 主图与 PDF 第 28 页 6010A 藤编扶手餐椅相符，实物 560×560×850 mm；旧 400×400 椅为示意。试点按实物尺寸建立完整椅子，并报告相对旧预留的 160 mm 增量，检查四座原位与桌腿、扶手 / 台面净距。若业主回复不采用藤编椅则保留此前椅向。新餐椅仅为测试候选，非采购决定。
- 吊灯：保持业主选择的浅色圆润 / 椭圆感和可擦洗要求。沿用已核查开口灯罩构造，以真实灯罩厚度、光源 / 吊杆 / 顶盘重建；避免复制 C 图纸 / 布灯罩不可擦洗表面。SKU 未定。
- 软装：B 参考的地毯 / 画作色块、织物与浅亚麻窗帘，保持实际位置，不添加 B 图未选落地灯 / 花器 / 搭毯。图案采用原创近似而非宣称商品同款。

## 成熟方法

已查本地库、前轮官方家具包和本轮图册型号检索，没有取得当前对应款的完整可用模型；不将相似款当同款。本轮依据整件实物 / 定制构造建立原型，材质继续复用 Poly Haven 原生 white ash / linen 节点。软包形状先用 Blender 官方闭合 cloth pressure 与缝边约束建立一件原型，经预览后用于同构造定制软包，替代不相关供应商部件拼装。官方方法：https://docs.blender.org/manual/en/5.2/physics/cloth/settings/physical_properties.html#pressure；它是形态生成方法，不是泡棉 / 羽绒力学认证。
