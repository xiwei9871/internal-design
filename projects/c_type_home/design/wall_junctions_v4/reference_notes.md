# 全屋墙体交界修正 V4

用户指出所有墙体交界应连续、齐平，蓝框处的板材式细缝/错位是错误处理。两张附件仅作为墙面连续性的现场关系证据，不从照片推算新墙厚/尺寸。

从最新V3继承。只处理活动实体墙：83个源墙网格，57套审阅墙面材质，4处约0.1–0.2mm的近接缝及多处共面/交叠接触。统一新墙壳外表面，去掉内部重复接口，修复毫米以下建模接缝。真正的墙角、门窗洞、不同墙厚和分层标高继承来源，不能把所有拐角压成同一平面。

轴向墙体源坐标中0.1–0.2mm CAD转换余差，在新墙壳输入副本上吸附到最近毫米坐标（最大0.21mm），斜门局部纠正墙保持精确源坐标。冻结B0、厨房、V1/V2/V3原文件不写回。厨房6个实体窗下墙/窗周墙由新墙壳同体量继承，原网格与姿态仍保存为隐藏源；其余266个厨房保护对象保持活动状态与全部属性一致。厨房尺寸、柜体、设备和窗口位置继续继承确认记录。

新模型保留原墙对象为隐藏来源，外显墙壳按共享平面单元和原有高度分层构成闭合实体，去除分段共面接口，统一连续墙面材质和面法线。墙面吸附余差最大0.21mm，连续饰面接触微量50微米，独立检验未改门洞范围之外的最大表面偏差0.30mm。独立重开检查外墙表面射线、网格闭合与内/外接口、门窗空间及D107红50/蓝0标注边界。

用户后续范围已包含所有缺失普通门、门套/门头/侧墙、客房推拉门贯通实际墙厚、休闲平台旁移门侧墙和门套，以及次主卧/主卧/现书房三个剩余飘窗。普通门按F-DOOR宽750/850，入户子母门350+750，审阅高度2100；已有D107和客厅北阳台门继承。客房G-GB-BALC旧代理Y10800移到实际墙带中心Y11000，原登记X跨度2000及高度关系保留。三处新飘窗沿用原投影700、窗台900/窗顶2850，连接上层吊顶3250，室内洞口不放第二层玻璃，外端及两侧返窗围合平台。
