业主已确认15房方向，制作了浅木、米白、简洁的真实场景候选。客餐厅延续既有家具与软装选择，客厅安装V10坐芯包覆/松填靠包形态；其余房间按合同完成实际木作、材质或陈设。外观仍待逐房人工验收。

## 实际改变

- 客厅完整木框保持，安装V10坐靠包并修复交叠。继续测试过的完整linen，不采用V9增加sheen的失败方案。最高约806mm、坐面约484mm，需适配与舒适度评审。
- 餐厅保留1600×800跑道桌、4张图册6010A真实尺寸椅与椭圆吊灯，无挂画。
- 厨房正确VIEW03窗族与冻结设备不改。窗外V3补光灯透射/反射可见导致白圆斑；关闭这两项，照明能量不改，实渲确认。
- 阅读柜820×320整体移到对面挂画墙，墙挂柜底505mm，与原矮柜顶25mm；新增定制墙撑，锚固承重待验证。扶手木色、3阶150/300/450mm。
- 母亲Creative05梳妆台按900×450定制U形，不采用Designer05。两组Creative床保留房间/床位尺寸；实际检查修复床垫离台12.5mm与床罩穿入，再单独重渲。
- 书房固定山水画与鼠尾草绿靠垫。主卫竖肋抽屉/开放层，其他卫生间保持原洁具拓扑。
- 北阳台历史1555宽阶梯柜：1800–2100开放350深，2100–2600闭合600深，门板前缘约618，不恢复旧700深上柜。
