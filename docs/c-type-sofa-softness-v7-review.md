## 未采用的真实模拟

1. `solve1`：在受支撑的内填充碰撞体上模拟外布套，实际烘焙两套 55 帧磁盘缓存。余量和柔软抗弯导致细皱遍布顶面、靠包及角部，灰模更像松垮罩布，拒绝。
2. `solve2`：一次关联修正，提高抗弯 / 压缩、收紧局部余量与缝边约束，并让内填充更靠近布套。两套 55 帧缓存完成，但仍有满面的细碎皱纹，拒绝。
3. 两轮 setup、静态候选、110 个缓存文件 / 轮及灰模证据都保留；独立重开后的 1 / 18 / 35 / 55 帧与报告中的变形、包络一致。最终交付没有使用这两轮模拟网格。

这说明本次参数与约束组合没有解决所需的松软感，不能推论所有布料模拟都无效。缓存完成只证明执行与复现，不证明真实海绵 / 羽绒力学或观感成功。

## 参考约束的静态候选

沿用前轮已查证的局部 height-alpha 思路，重建少量缝边凹陷和宽缓的填充分布，减少对称、绷紧和侧围平直感。保留 UV 与原有完整材料，不使用全表面周期 / 随机噪声。通过 Shape Key 编辑，不声称原生笔刷成功。

初次 `local_form` 的坐包边缘鼓成一圈凸棱，在灰模中拒绝该细节。`local_final` 降低该隆起 / 褶皱深度，转为缝口内收与侧围弧度；前版仍保留。背包重新落在实际坐包上，并保留对木背架的局部压缩与缝边附着。
