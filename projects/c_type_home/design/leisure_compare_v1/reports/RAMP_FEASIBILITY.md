# 休闲平台 A/B：坡道可行性与建议输入

**局部短坡不可作为轮椅坡道；B直梯是可研究的几何方案，不是已批准拆改，也不能使整屋无障碍。** 两方案只比较R4休闲平台和0→450 mm过渡，上层走廊、房间、门窗均保留。

## 定量核算

| 项目 | 数值与意义 |
|---|---|
| 高差 | 450 mm |
| 1:12坡道水平段 | 5400 mm，坡度8.33% |
| 本次粗略平台比较 | 两端各1500 mm，总长8400 mm |
| Access Board原文平台 | 各60 in（原文公制1525 mm），总长8450 mm；60 in原始换算为1524 mm，总长8448 mm |
| 原扇形局部外包 | 1500×1900 mm；不足容纳坡段，更不足容纳两端平台 |
| 把450高差塞入1900长坡 | 23.68%，约1:4.22、13.32°；作为轮椅坡道不可用 |
| 1900长、1:12可克服高差 | 仅约158 mm，未计平台 |
| 红色研究坡段 | 5400×1100 mm，x1.8→7.2、y5.0→6.1；坡段面积5.94 m²；**关闭／研究用，未采用** |

美国Access Board原始[ADA §405.2](https://www.access-board.gov/ada/#ada-405_2)：“Ramp runs shall have a running slope not steeper than 1:12.” [§405.7.3](https://www.access-board.gov/ada/#ada-405_7_3)：“The landing clear length shall be 60 inches (1525 mm) long minimum.” [§405.5](https://www.access-board.gov/ada/#ada-405_5)将扶手之间净宽列为36 in（915 mm）。这些仅作为美国参考基准，**不是中国规范合规判断**。1500 mm不能写成该原文的精确要求。原文既有建筑陡坡例外也仅容许更小高差，且禁止陡于1:8；450 mm／1900 mm不属于可借用例外。

完整直坡加平台，若仍按1100 mm宽，参考占地约9.295 m²；扶手／边挡还可能增加外包。红色模型只有坡段，未含两端平台、扶手和门口回转，不能表示完整可实施坡道。其x1.8起点越过西墙x2.7–2.9，y5.0–6.1又不完全落在ENT-1登记门跨y5.44–6.54内；入户与餐厅通行也产生筛查冲突。这是冲突展示，不切墙、不算作选用通道。

## A／B建议输入

| 比较 | A 保留扇形 | B 移除扇形＋紧凑直梯 |
|---|---|---|
| 空间作用 | 保留抬高休闲区、弧线连续和原上层走廊关系 | 释放原扇形占用位置供下层灵活用途；上层走廊仍450 mm |
| 台阶 | 原直段150高×200进×3、宽1200 mm | 150高×300进×3、宽1200 mm；进深总900 mm，投影1.08 m² |
| 几何比较 | 2R＋G=500 mm；原直段坡向比参考36.87° | 2R＋G=600 mm；新直段坡向比参考26.57°，踏面增加100 mm |
| 无障碍 | 未建立轮椅过渡 | 仍有三级150 mm台阶，不能称整屋轮椅可达 |
| 实施确定性 | 作为少干预基线 | 拆改结构未知；需确认楼板／梁／钢筋／管线和梯顶连接 |

B新梯x6.3–7.2、y5.0–6.2，名义900×1200 mm包络能够跨越450 mm高差，并在x7.2接上层；最终评估几何仍须验证每级踏面、梯顶无缝接合、上下站位和通道。几何“能放下”不等于原扇形可安全拆除。

若重点是未来下层灵活使用，**B更值得继续深化，条件是结构拆改和梯顶连接确认**；若重点是当前少改动与确定性，A应作为保留基线。两者都未解决轮椅跨越450 mm高差。扶手、临空边保护及老人实际使用仍需深化。

回收面积交由主模型按实际扇形减去保留走廊和新梯计算，当前不填。1500×1900=2.85 m²只是外包矩形面积，不能当成净增可用面积。

原始网页和逐条摘录保存在本目录的`../references/`；机器可读量化数据见`RAMP_FEASIBILITY.json`。此记录未修改R4或任何Blender构建脚本。
