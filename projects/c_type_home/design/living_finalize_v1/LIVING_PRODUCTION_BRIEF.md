# 客厅定稿实施 V1｜制作合同

源：不可变 R4 OPTION_A_SLIDING_R4；所有改动进入 LIVING_FINALIZE_V1.blend。单位米，家具/净距报告用毫米。仅客厅：L型浅白蜡木主沙发、米白亚麻、窗边独立贵妃、图3定位带中的边柜（门朝南/厨房）、新茶几A/B。柜面一主花瓶带枝叶、一小陶器，可一本书。不保留额外双人位或旧双圆茶几。

阶段：资料/尺寸 → 布局灰模与路线 → 实际框架/软包/柜门抽屉/支撑 → UV与物理材质 → 光线预览 → 原生最终渲染 → 重开模型/几何/文件校验。

预算：新增主家具约30–80万评估三角，重要家具木纹/布料2K–4K真实纹理，几何细节按2048×1365以上最终图的特写距离制作。桌沿/柜沿真实毫米圆角，软包曲率/拼缝有实体支撑。场景原几何保留，不使用移墙/新门窗/虚构灯洞改善画面。

主渲染：Cycles；优先Metal GPU，明确CPU退路。先768–960像素32sample低成本诊断；最终至少2048×1365，128–256samples，OIDN final单次去噪，AgX，白天自然光为主/克制暖光为辅。先检实质材质/曝光/玻璃，再决定是否提升采样，不靠过曝隐藏问题。

七张：main/reverse/chaise/sideboard/wide及同机位coffee_A、coffee_B。茶几A作为默认场景；B为真实独立Collection/ViewLayer或Scene变体。支持render-only显示状态，保留既有天花板几何；不添加不存在的建筑。

图册只作尺寸/木色/构造语汇依据，不复制产品照/完整产品；PBR外部来源记录许可并打包，版权图册页只存参考区。所有图、材质板、平面/机位示意保存在项目，聊天返回路径。

若家具尺寸/动线不能同时成立，先在用户允许范围缩柜/微调活动家具；建筑改动仅列DESIGN_DECISION_REQUIRED。不得因用户任务书明确授权本轮实施而再次要求例行确认。
