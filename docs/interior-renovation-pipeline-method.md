# 住宅改造设计管线方法论（通用）

2026-10-17 · 从 V15 全屋项目沉淀。与项目无关的可复用流程。

## 管线全景

```
原始户型图(FreeCAD/DXF)  ──► Blender 改造模型 ──► 效果图渲染 ──► 灯光设计 ──► 施工图(DXF)
        ▲权威底图                ▲设计真源            ▲3条路径        ▲用途审计      ▲双源对照
```

### 原则：两个权威源，互不臆造

- **原始户型 DXF**（FreeCAD 导出、规范图层、尺寸链、门窗编号）= 结构与尺寸权威。所有施工图以它为底图复制起步，绝不重画。
- **Blender 设计模型** = 改造设计真源（新墙、拆除、家具、灯具、洁具、材质）。
- 坐标系先验证一次（比对西墙/南墙位置），确认零偏移后双向可映射（单位 mm）。
- 图像（效果图/俯视图）只能辅助判断，**不能反推墙体、洞口、管线拓扑**——一律取对象几何。

### Blender → 平面几何（详见 `.codex/skills/blender-plan-geometry-extraction`）

- 按坐标区域查询对象（名字不可靠）；`frame_set` 到全可见帧取 evaluated bounds
- 墙 = bbox（z0≤600 且 z1≥1800）；吊柜/过梁/地台按 z 过滤
- 合并 SHELL 墙 → 顶点云 → 栅格化膨胀 → 掩码
- 异形（波浪台阶/曲面家具）→ loop 三角形投影 XY 求并集 → 真实足迹；z 顶面决定级数与上下行方向

### 渲染三路径

1. **AI 绘图（image2）**：快速风格探索
2. **V-Ray**：正式品质；离线 denoise 不解决材质本质问题
3. **Blender EEVEE/Cycles 静帧**：模型自查/快速验证

经验：不要在渲染后处理上修材质——**模型本体达标**（材质、灯光、几何）才是目标；视口 Material Preview 里好看 = 模型真的好。

### 灯光设计纪律

- 日/夕/夜分态；白天纯自然光、禁用窗面补光、夜间只用设计灯具；天花实体挡光（仅洞口透光）
- 每盏灯对照用途审：柜下灯沿柜向、床头灯在床外、镜前灯对镜子实体坐标——逐条核对，不靠名字猜

### 施工图管线（详见 `.codex/skills/interior-renovation-cad-docs`）

- 墙体 = 基准墙 vs 模型掩码逐段 diff → 拆除（红虚线）/新建（粗黑）/保留（细灰）
- 地面铺装 = 材质编码俯视图像素分割 → 永不越界的铺装区 + 设计意图人工覆盖（每条覆盖都要业主确认）
- 图符分级、门槛石只在材质交界处、图例+中文说明+标题栏+冻结校核层
- `待现场复尺` 标注一切模型未建/未确认项（坑距、配电箱、检修口）

### 验证循环

渲染 preview PNG → 与模型俯视/业主参考图对照 → 改 → 一键重渲全部预览。任何图不达标不宣布完成。
