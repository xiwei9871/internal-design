## 4. 黑/白墙判定(原图白=NO-OPENING 声明)

判定依据优先级:实测 HATCH 结构填充 > 外墙包络 > 厚度≥180 > 原图像素填充采样(辅证)。
结果:**23 面 `OWNER_DECLARED_NO_DEMOLITION_NO_OPENING`**(全部外墙 + 200mm 以上内承重带:X9800/X11500/X13000/X7900-L/Y4500-a/b/bc/COR-N-STUB/BEDN-S/WC-S/STD-S/Y10800 等)。

**关键发现(影响次主卫方案)**:原衣帽间**南墙 Y4500-b 为白墙** → 次主卫 Option S(南向卧室开门)需新开洞 → **被规则禁止**;Option W(西墙,原黑墙位置重建)成为唯一合规入口。

**反例警示**:CLK-N 在原图呈白填充却被业主实际拆除 —— 说明"白色"是开发商图纸画法/业主声明,不等于已证实的结构属性。施工前仍需正式结构核验。
