## 色彩转译

白蜡木 p4/p8/p10/p11/p25提供浅暖沙色木质基调；琥珀木 p30/p38/p43/p63可取暖木与象牙软包、灰白背景的关系，以及开放木架，而不将整屋改为深棕。预览建议色（**非厂商校准色号**）：浅白蜡木 #C8AF8C–#DBC7A8；象牙麻布 #E5DFD2；浅暖石 #D8D3C8。琥珀 #A86F38仅作少量可移动小物点缀，若不必要可省略。保留低饱和开孔木纹、柔和哑面；不重染墙、地、固定柜或整套家具。
