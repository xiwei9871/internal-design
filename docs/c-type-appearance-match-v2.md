## 参考观察与颜色

已查看选定 A 及本地白蜡木图册。参考白蜡木呈浅蜂蜜色、软包呈暖燕麦灰，墙面暖米白。展示色的起始色卡：木材 #C7AA80、布艺 #BEB3A0、墙面 #DED5C7、窗帘 #D9CFBE、深金属 #55514A。这些是受光后的视觉锚点，不直接当作线性反照率。纹理资产仍使用已验证的 CC0 ash_veneer 和 rough_linen；布料的蓝色仅作为扫描源，将纱线明暗归一化后着色为真实燕麦色。

## 已查明的具体原因

- V1 将线性 shader 基色设得过亮。织物使用 .80/.74/.63，忽略这些线性数值比同值显示 RGB 更亮；有扫描不等于有可见织纹。
- 旧材质函数在没有材质槽的网格上直接返回家具木材，FLOOR_LOWER 没有取得地板 shader。
- 木材统一世界平面投影，腿和扶手的纹理未沿各自构造方向。
- 射线验证：V1 沙发测试点 (4,9,.45) 到太阳首先命中北窗内窗头，茶几点命中上横框。调整太阳角度需遵守真实窗洞，不能删除墙或天花。
- 透明窗的阴影传输需要与薄建筑玻璃一致，在保留视线反射/折射的同时检查直接日光通量。
