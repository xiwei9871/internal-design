# 从真实物件建立精细模型

2026-10-10 业主要求解决方法上的问题：沙发及任何物件都从实物出发，先用桌面图册 / 产品资料，再找匹配模型或按产品建立整件，避免继续逐处修补布局简模。

## 当前沙发的处理决定

V1–V3 和冻结源文件保留；旧沙发仅继续承担已有明确来源的占地、位置及空间适配约束。没有产品依据的旧软包缝隙、模块内部形状和分件比例不强制保留。V3 借用 Fly SC2 的软包与旧简模木框组合，没有建立同一真实产品的整套沙发；用户指出大缝隙和整体造型不符，不能当作已验证家具库资产继续复制。

前轮 read-only 核查确认：旧坐垫包络缝隙 70 / 60 mm、旧背垫 90 / 70 mm，被 V3 继承；OBJ 导入旋转未在分件提取中完整应用，造成软包深度 / 厚度轴交换。修复这个脚本错误仍不足以把拼合件变成真实款式。本轮不修改该模型，先纠正物件来源与建模入口。

用户选择的 A Faithful 家具外观和浅原木 / 米白方向继续有效。图册实物原型与该方向做整体匹配，不默默改换商品型号。真实产品规格与旧家具占地不一致时单独报告适配问题，不能从效果图量尺寸，也不能为了使用模型把实物任意拉扁。

## 简单且可重复的流程

**真实产品 / 有依据的定制构造 → 对应整件模型 → 单件与实物核对 → 放进真实空间。**

1. 一件物品绑定一份实物记录：来源、页码 / 型号、整件结构、尺寸、材料 / 饰面。已确认实物无需每个缝线再问用户；只有换款、尺寸冲突或关键未知信息才提出具体决定。
2. 优先找同款完整模型，检查 UV、材质、单位及来源。只有相似款时先比整件结构，不能仅因为软包细节漂亮就借来硬拼旧木框。
3. 没有同款模型时按同一真实产品建立整件，以产品资料确定扶手 / 腿 / 座面 / 靠背 / 软包如何组成和支撑；未知背面或连接记录为待核实。算法与材质可借鉴成熟方法，但不发明产品身份。
4. 空间模型只决定真实建筑和当前确认的布局约束。产品真实尺寸与预留占地分开；不把旧示意坐垫缝隙变成固定尺寸，不用整体拉伸解决商品不适配。
5. 完整家具单独通过实物主 / 侧 / 背面与材质检查，再入房间同机位比较。通过后按该型号 / 定制构造保存至项目资产库，后续复用整件及接受记录。
