# 资产与成熟方法优先

制作或修正家具造型、材质质感、布料与灯光前，先查当前项目已经实现的方法与本地图库，再查厂家官方资产及可靠模型 / 材质库；合理检索后仍没有合适方案，才针对缺口自研。记录已有方案为什么不适合，避免仅凭“难找”重新从零建模。研究资料不自动授权改模型、购买、安装插件或重启批量队列。

## 家具

先比已选造型：木框、扶手 / 靠背、坐垫轮廓 / 厚度 / 倾斜、缝边、支撑和负空间。查看实际产品图及模型预览，不能只凭搜索摘要或 photorealistic 标签。优先对应厂家资产或兼容的精细模型；简化 BIM / CAD 模型不自动符合精细渲染要求。

检查原生格式、单位、UV、纹理依赖、材质引擎、授权和可编辑分件。.blend 优先，OBJ / FBX 可交换几何；.max / V-Ray / Corona 的材质参数不能假定可直接用于 Cycles。作者未提供 UV、交换格式或许可时明确记录缺口。

真实模型决定尺寸和位置。适配按木框、坐垫和模块构造进行，不把整套沙发非均匀拉伸到包络内并称为完成；也不能为使用库存资产擅自换已选家具。轮廓 / 缝线 / 下垂 / 支撑受压属于几何问题，纱线与木孔属于微表面问题，分开解决。

## 材质与参数

优先供应商完整材质 / 原生节点或官方导入方法，而不是只借三张图后任意叠加参数。保留扫描的颜色、roughness、normal 和需要的 IOR / 纤维方向 / displacement 信息，核对物理尺度、法线方向、色彩空间、UV / 切线与当前 Blender 版本。缺图不意味着所有材质都必须使用同一清单。

“成功参数”是材质、真实尺度、表面、灯光、渲染版本与参考结果的组合，不是一组全屋通用 roughness / specular 数值。先在固定中性光下复现供应商结果，再调整已选颜色与饰面，最后放回真实房间比较。旧教程或其他渲染器的参数要经过兼容性转换；Sheen / bump 不能替代坐垫造型和褶皱。

## 证据与复用

分清状态：FOUND → PAGE_VERIFIED → FILES_INSPECTED → BLENDER_IMPORTED → CYCLES_VALIDATED → OWNER_ACCEPTED。未实渲的资产不能称“已验证成功”，单件在中性光下正确也不证明房间照片感已匹配。

通过当前项目的近景 / 主图及人工选型后，再纳入专用资产库：记录来源、品牌 / SKU（未定则标明）、许可、版本 / 引擎、物理尺寸 / 贴图尺度、文件哈希、原预设、必要修改和接受证据。后续先复用这些已验证资产 / 材质，不重复从零调。

## C-Type 的使用决定

2026-10-10，业主认为 V2 颜色和材质有较大进步，家具样式和质感仍有明显差距。后续重点为成品软包 / 木框资产与完整扫描材质。库里其他型号仅为候选或结构质量参考，不能自动替换 A Faithful 已选家具；尺寸仍忠于真实模型。具体来源及访问限制记录在项目 docs/c-type-asset-method-research-2026-10-10.md，不把当日价格或未检查的格式写成通用事实。
