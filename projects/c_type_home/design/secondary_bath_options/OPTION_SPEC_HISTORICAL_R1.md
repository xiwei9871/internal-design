# 次主卫隔断方案对比（从基础版 V1 分支）

基础版：[HOUSE_BASE_GEOMETRY_V2_FROZEN.blend](/Users/xiwei/interior_design/projects/c_type_home/design/wall_corners_v5/HOUSE_BASE_GEOMETRY_V2_FROZEN.blend)。黑色实心墙体保持；白色可调整墙体只在方案分支中改。当前书房南侧蓝框开口按现状保持开放，不在基础版里补墙。

## 已知空间与尺寸依据

- 原始衣帽间/现拟次主卫区域：R-CLOAK，约 2250×1650 mm（CAD exact polygon：x9050–11300，y4650–6300）。
- 现有审阅洁具：台盆柜约1000×500，坐便器约500×600，湿区约823×1547；这些是审阅包络，SKU和安装净空仍待复尺。
- 南侧入口：本轮两个方案都从南侧进入；不改变黑色实心墙；南侧可调整段按白色墙体/现有开放段处理。
- 厨房与全屋基础版几何不变。方案分支只增加可逆的隔断墙和门，不回写基础版。

紧凑台盆参考：Lusso 官方 600×400 mm 壁挂盆，H150；官方产品页说明适合 cloakrooms / powder rooms。紧凑盆常见范围约400–500mm宽、100–200mm深；最终选型仍按现场排水、台面和设备复尺。

## 方案 A：南侧推拉门（推荐）

采用南侧单扇推拉门，门扇沿南侧外墙/可调整墙面滑行，卫生间内不占开门回转区。门洞按约850mm正常门宽做审阅包络，配门套、上轨、止口和连续墙体；推拉门不占洁具前方操作区。

优点：小空间最稳妥；不会与坐便器、台盆或淋浴入口发生门扇回转冲突。代价：南侧外墙需要一段连续停车墙面；需检查走廊净宽、门扇与现有卧室门套/柜体关系；上轨和门扇厚度需定型材。

## 方案 B：南侧内开平开门

采用南侧单扇平开门，约850mm门扇向卫生间内开启；门套、上方墙体和两侧墙垛按永久门规则完整建模。门扇铰链方向需与台盆/坐便器净空一起比较。

优点：构造简单、隔音和密封更熟悉。代价：门扇回转占用卫生间内面积；在约2250×1650区域中，必须把回转区从坐便器和台盆前净空中扣除。

## 比较结论

A 更适合当前面积和洁具包络，先作为推荐方案；B 作为构造简单的备选。两方案都不能进入加工/施工图阶段，直到确认南侧实际可调整墙段、走廊净宽、门扇停车或回转、排水点和洁具 SKU。

两方案在用户选定前保持为设计提案，不能写入基础版。
