## 支撑检查与生产平滑

`form1` 顶点支撑距离约 1.2 mm，但五层侧围面片跨越了凸起坐垫：BVH 报告 241 对座 / 靠包交叠，定位到后侧围过长面片在两端顶点之间切入曲面。没有将顶点间距通过当成面片通过，保留失败候选和灰模。

`form2` 将侧围插值环 5→15，接触余量改为 1.8 mm，并为坐垫后缘之外的短靠包边缘提供连续支撑参照。原来的整包位置保持，接触变化局限于下部；面片穿插检查通过。坐垫底与木承托共面属于有意接触，改为核查是否沉入木板；没有笼统拒绝全部接触或放宽其它穿透检查。

未平滑实渲暴露出缝口转角偏硬。完成一级可编辑 Subdivision 曲面平滑，缝边转移到评价后的表面。首个 delivery 构建因“评价后顶点顺序与控制网格相同”的假设断言失败，只修正一次为最近表面投影，未保存该失败交付。正确交付重新通过闭合、接触、三角面与源保护验证。没有通过抬高曝光、换布色或增加采样掩盖这个几何问题。
