# Lighting review procedure (data checks)

Run on any proposed lighting point set before drawing it.

| Check | Rule | Severity |
|---|---|---|
| In room | ceiling points inside their room zone; wall/plinth points within 300 mm of it | FAIL |
| Over full-height storage | no ceiling point above furniture whose top is within 600 mm of the finished ceiling | FAIL |
| Over bed | no ceiling point above a mattress footprint (+150 mm) | FAIL |
| Step line | no recessed point within 350 mm of a ceiling step line | FAIL |
| Colour range | CCT within the owner range | FAIL |
| Traceability | every original point has an action: KEEP / MOVE / REMOVE / CONVERT | FAIL |
| Elderly night route | the mother's bed-to-bathroom route has ≥1 night point per segment and a control | FAIL |
| Wet-area zones | points inside a shower footprint are flagged for electrical zone review | FLAG |
| Photometry | no illuminance/glare compliance claimed without IES/LDT data | FAIL if claimed |

Severity FAIL blocks the candidate drawing; FLAG goes to the open-items list.
