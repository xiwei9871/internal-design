# C-Type 资产复用精细模型 V3 合同

2026-10-10 业主授权按新路线制作一版模型。范围：客厅与本次消息指定的厨房；已异步询问是否指今天圆桌所在餐厅，若纠正则调整第二空间。客厅工作不依赖这个答复。

- 输入：独立 appearance_match_v2/LIVING_DINING_APPEARANCE_V2.blend；原模型、V1、V2、R4、B0、厨房冻结 V1 和参考图全部保留。
- 客厅：A Faithful 主体家具与布局，B Designer 已选地毯 / 窗帘 / 东墙画，无 Creative 元素。只借用供应商软包几何，不自动添加 Fly 的装饰抱枕，不更换整套木框款式。
- 本轮已取得 &Tradition Fly SC2 官方 OBJ、原厂纹理与不同精度版本，检查在隔离文件中完成。使用供应商坐垫和背垫的轮廓、受压、缝边、UV；按每个实际软包包络分件适配，纹理按米制重定密度，记录具体源部件。定制木框、茶几与低柜继续按真实尺寸。
- 材质：取得 Poly Haven rough_linen 与 ash_veneer 原生 Blender 材质、完整依赖；保留原始节点和反射 / 纤维方向 / normal / roughness 方案。只做与已选米白布 / 白蜡木色一致的必要调整，使用 .3m 布艺 / 1m 白蜡木扫描尺度，原供应商方案有单件对照证据。
- 厨房：只深化现有 Faithful 主材、面板、金属、台面、灯光和设备可见细节。冻结布局、尺寸、柜体数量、门窗、标高、管线关系不改；厂家设备仅是机制参考，SKU 和安装开孔未确认。读 CODEX_HANDOFF_B1.md 与厨房冻结清单，引用库若没有正确的双燃气灶/烟机，则保留真实设备并按此前官方参考局部细化；禁止导入错误电灶代替。
- 顺序：资产文件核查 → 供应商单件几何与原材质测试 → 实际尺寸适配 → Workbench 预览 → 少量 Cycles lookdev → 同机位前后实渲 → 重新打开 / 源几何 / 包络验证 → 一版可编辑打包 .blend 和评审网页。
- 仅任务主图与必要近景 / 反向检查，不重跑全屋队列，不调用 Image2。
- 数值校验与外观匹配分开；只有实际图中软包造型、木色、织纹、反射和灯光可读，才评估改善。不以贴图数量或网格数量宣称达标。
- 供应商资产和模型二进制留本地；许可记录来源，用于本项目设计试点，不把厂家模型或纹理当自制资产分发到 Git。
