# 错层弧形区 A/B 空间研究

建议优先深化 **B：移除弧形平台，采用紧凑直梯**。它把主要会客空间的边界简化，净回收约2.28㎡下层地面，三级150mm高差仍真实存在。**该建议以现场确认弧形平台为可拆构造为前提；模型不证明结构可拆，也不批准施工。** A有清楚的建筑曲线，但在本轮300mm踏深条件下会额外消耗约2.60㎡下层地面，收益主要在视觉而不是通行与长期弹性。

## 两方案的真实构造

**A｜FAN_PLATFORM_RETAINED**：保留原约2.635㎡弧形平台，定位“上层过渡与缓冲平台”，默认留白，不作为第二小客厅。沿既有弧边向下层作300mm法向偏移，两道低踏步标高+150/+300，第三次抬升至+450顶平台；原直阶与弧形边缘通过连续偏移曲边整合。顶平台局部向旧台阶带延伸约0.660㎡，平台与踏步总平面约5.951㎡。其曲线值得保留的理由是建筑秩序和坐靠/短暂停留潜力；若主要目标是释放客厅或适老化，这份完整弧阶的地面成本偏高。

**B｜FAN_PLATFORM_REMOVED / B1**：移除原弧形平台占地及旧三阶，原位置降为下层FFL0；保留剩余上层走廊与房间FFL+450。新直梯位于X6.30–7.20/Y5.00–6.20m，宽1200mm；三级抬升各150mm，名义踏深300mm，总水平包络900mm。第三道与上层同高，是进入上层的末级/平台，并不是第四道150mm高差。两低踏步的舒适性公式2R+G为600mm，旧200mm踏深对应500mm。

B上端1200×1200mm候选平台范围位于既有上层楼面中，楼面覆盖已核查。边缘、扶手、止滑、照明、原门扇开启与通道最小净宽仍应在下一步节点设计/现场检查，1200mm楼梯宽不等于全部路径都具有1200mm净宽。原入户1100mm名义双扇门不变；仅开启750mm主门扇时不能声称满足900mm净通行。

## 六项比较

| 比较 | A | B |
|---|---|---|
| 空间完整度 | 曲线更整体，但宽踏步继续向客厅伸出；地面用途仍是过渡 | 回收平台让下层连贯，避免一个难布置的第二客厅；新梯仍有固定占地 |
| 交通流线 | 多方向可登阶，但曲线端部/窄角应避免成为随意入口；占下层更多 | 上下层转换集中到直梯，方向更清楚；上端平台及门扇需核验 |
| 视觉秩序 | 曲线是亮点，楼面曲边被完整解释 | 主会客区更安静，过渡退到原上层边界；失去原弧形焦点 |
| 功能合理性 | 最适合留白缓冲、短暂停留；不建议第二套沙发 | 更适合把日常活动归并主客厅，回收地面保持弹性 |
| 适老化潜力 | 仍三级障碍，曲阶和开敞边缘需扶手/止滑；没有完整轮椅坡道 | 直阶更易读、便于辅助把手/照明，未来有局部平台升降装置研究弹性；**不等于已无障碍** |
| 改造复杂度 | 曲线踏步定制、弧形收口、前沿整合复杂；仍要核原台阶构造 | 平台拆除与地坪补齐可能涉及结构、管线、防水/声学；几何施工较简单，但拆改风险可能更高 |

## B2 坡道研究：不可行

450mm高差按1:12（8.33%）需**5400mm**水平坡段。参考两端平台各1525mm，整体长度约**8450mm**；1100mm净宽假定下总平面约9.30㎡，还未计扶手结构/侧边防护额外厚度。原弧形包络约1500×1900mm，无法在其中装下。

若强塞1900mm坡段，坡度为450/1900=23.68%，约1:4.22。**该空间内完整安全坡道不可行/较不合理，仅作研究示意。** 两分支的红色研究集合按真实5400mm坡段、两端1525mm平台建模，它穿过既定西侧墙/入户/餐区交通，未作为A/B实施方案。图上没有用一块“看起来缓”的短斜面代替正确尺度。

坡道数值参考US Access Board ADA §405.2、§405.5、§405.7.3，原网页和摘录留在references；是跨标准的尺度研究，并非本项目中国规范或施工合规证明。当地适用规范、扶手、防护、老人实际需求和可用设备必须再核对。

## Recommendation

- **Preferred Option: B（有条件优先深化，非施工批准）**。
- **Reason 1**：下层净回收2.28㎡，主客厅的活动与家具布局自由度更大，避免将休闲区重复定义为第二客厅。
- **Reason 2**：1200mm直梯、150mm抬升与300mm踏深关系清楚，较现有200mm踏深更容易做止滑、侧扶手与照明。
- **Reason 3**：收紧过渡体量，为未来局部平台升降设备或辅助通行装置保留研究弹性；两方案都不支持短坡冒充无障碍。
- **Main trade-off**：失去弧形建筑亮点，拆平台的结构/管线风险高于表面视觉改造；若现场确认不可拆，应回到A或更小幅原台阶改善，而非硬拆。
- **Next**：先核结构剖面、平台材料/空腔/承重与管线；确认B上端平台门扇/扶手净距，再与客厅L沙发+窗边贵妃+边柜的正式家具布局联动。当前没有决定采用B，没有回写R4/FreeCAD或扩展其他房间。
