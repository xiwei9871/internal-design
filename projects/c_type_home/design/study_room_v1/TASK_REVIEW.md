## 当前布局（R4 茶台尺寸调整）

- 茶台／工作桌 2000×800mm；南端延长 500mm，北端保持原位。桌面西边界 X14.21m、东边界 X15.01m，Y7.58–9.58m。
- 主通道在桌子正面／西侧：模型净距约 1110mm。
- 椅子 500×500mm。桌边到书柜前沿 750mm；500mm 椅子＋300mm 椅背余量－50mm 椅子前沿伸入桌下，不当作过人通道。取消椅子前沿与桌边之间额外的 200mm 空隙，腿进入桌下。南侧茶水边柜到桌端约 473mm，不作为过人路线；主人从北侧约 920mm 的空间绕入。
- 窗边固定 Daybed 1880×1200mm；现有台板实测 2200×723mm，墙垛决定可连续使用的净长度。固定家具延伸 550mm，墙体保留，因此实际封闭储物柜深约 390mm。
- 日常座垫约 610mm 深，前方保留木平台，三个抽屉；住宿使用薄垫代理，不设独立沙发床。
- 后墙 4000×380×800mm 封闭柜，上方 300mm 深开架，中央留白 1550mm。开架占新上柜横向带宽 61.25%，留白 38.75%；不是全墙重复格子。
- 现有茶水柜、水槽、给排水对象、墙体、门窗和楼层均继承不改。

## 两种状态与检查

Daily：Daybed 到书桌 920mm；正面主通道 1110mm。Guest：书桌南移 350mm，椅凳收至桌下，床前约 1270mm；正面通道仍 1110mm。850mm 的现有门控制整条进出路线的最窄点。

已检查新家具与局部墙、窗、门的几何干涉，以及门扇 0–90° 每 5° 的家具避让。Daily/Guest GLB 经新场景导入，分别 112/108 个稳定实体，ID 对照一致。冻结 R4/B0 的 SHA-256 前后不变；其它继承对象通过退休家具名称白名单进行状态比对。

待审：薄垫的实际折叠包装是否能进入抽屉，厚床垫尚未验证；抽屉拉出后的 470mm 为取物空间，需要核对使用舒适性，不能描述成通行宽度。人体、具体设备型号、柜门安装与规范合规均不以此几何代理认证。

## 复现与本机依赖

生成物在此目录及 Spatial Canvas 的 `task-output/study_room_v1`；不加入 Git。当前本机来源、稳定 ID registry 和墙段 index 的绝对路径由脚本显式指定，不能用另一个相似文件替代。Spatial Canvas 仅作为现有导出器使用，本任务没有改动它的代码。

依次运行以下源脚本（Blender 5.2.1）：

1. `audit_study_room_v1.py`：仅书房命名对象与最近建筑上下文。
2. `build_study_room_v1.py`：生成同一继承设计的 Daily/Guest 文件、局部净距报告。
3. `preview_export_study_room_v1.py -- daily` 与 `-- guest`：简单 Workbench、任务 GLB、导入 ID 核对。
4. `top_plan_study_room_v1.py -- daily` 与 `-- guest`：俯视切片，隐藏上部遮挡只发生在渲染进程。
5. `package_study_room_v1.py`：用本机 bundled Python/Pillow 标注尺寸、整理报告及产物。

不要对冻结 R4/B0 保存；不要自动合并；本轮停止在空间方案人工审阅，高质量 Cycles、Image2、美化与施工深化均未开始。

本轮未增添永久多把客椅。用户指定茶席来客坐侧面／对面的使用方式；多人落座后的通行与具体座椅包络需另作审阅，不能用空桌通道净距表示坐满人的通道宽度。Guest 时桌子南移后边柜间隙约123mm，该间隙不承担通行。
