## 审查 5727854850 整改

**P0 路由连通性**：原 `offset()` 对每段单独平移（横段只移 y、竖段只移 x），各系统转角和源头接口因此断开 120–240mm。现改为每个系统整体平移 (d, d)，并从真实源头补一段正交短接。新增 `mep_topology.py`：先在交点处拆分线段，再按共享节点判断连通，容差 1mm，120mm 的缺口不会被当作连通。任一终端接不通，`mep_qa.json` 结果为 FAIL。

| 系统 | 整改前（从源头可达） | 整改后 |
|---|---|---|
| POWER | 70/70 段，终端 51/51 | 70/70 段，终端 51/51 |
| DATA | 1/15 段，终端 0/7 | 16/16 段，终端 7/7 |
| COLD | 1/29 段，终端 0/14 | 31/31 段，终端 14/14 |
| HOT | 1/19 段，终端 0/8 | 21/21 段，终端 8/8 |

整改后各系统偏移改为正向（弱电 80、冷水 160、热水 240mm），避免平移后进入楼梯区和 x<8000 的无吊顶区。

**P1 施工边界**
- 穿墙：线段与墙体相交 64 次，**不是开孔数**。按 400mm 去重后为 28 处位置：结构候选 10、墙体属性未知 15、新建隔墙 3。除新建隔墙外一律 `HOLD: STRUCTURAL_SITE_VERIFY_REQUIRED`（A301 红色菱形），未经结构确认不得打孔。明细在 `data/mep_routes.json` 的 `wall_crossings`。
- 水电交叉 36 处，只是平面交点，见 A301 注记 12。150mm 下返不代表四套管线都能装下。
- 照明线路**未建模**：A201 V2 的 103 个灯具、20 个开关、5 个感应器的接线不在 A301 里（A301 注记 10）。
- S42：`ELECTRICAL_ZONE_PENDING`，电气确认前不作为可施工位置（A302 注记 8）。
- E01/E02 紧急呼叫只有点位，接收端、供电和失电处置未定，**不构成有效紧急呼叫系统**（A302 注记 9）。
- 源头、线路长度、交叉数量都基于假设，不能当作材料量。
