# DESIGN_RULES_POC_V01 — 规范资料整理（简版）

日期：2026-11-01 · 分支：`design-rules-poc-v01`（基于 `cd-a202-a201-v01`）

业主定位：本项目是业主自家装修的设计初稿，用来向设计和施工团队说明设计意图。规范的最终确认由设计和施工团队负责。
因此本轮只做轻量整理，不做深入法规研究，也不做 A/B 对照实验。

**状态：`REFERENCE_REGISTER_COMPLETE / DESIGN_CAPABILITY_NOT_TESTED`。** 测试只检查登记格式和条款级废止关系，不证明逐条摘要准确。

**适用性要点**：本项目是既有住宅装修，直接适用的是 JGJ 367-2015。
GB 55038-2025 中针对"新建住宅"的条文（例如层高 3.00m、净高 2.60m）不直接套用。
它在公告里写明：既有建筑改造如果不改变使用功能，在条件不具备时，可以不低于原建造时的标准。

## 3. 对本项目有用的结论（交设计/施工团队确认）

| 事项 | 依据 | 结论 |
|---|---|---|
| 吊顶后净高 2650 | JGJ 367 第 4.3.2、4.4.2 条：装修后不低于 2.40m | 初筛未见冲突（设计值），需现场复测 |
| 楼梯旁局部净高 2350 | 该区在台阶顶部/走廊，不属起居室或卧室，JGJ 367 第 4.3.2、4.4.2 条的 1/3 规则不直接适用；GB 55031 第 3.2.7 条（最低处≥2.00m）只是通用底线；若认定为套内前厅通道，JGJ 367 第 4.2.2 条要求≥2.40m | 初筛未见明显冲突，需逐踏步复测并确认空间归属与适用条款 |
| 主卫（母亲）不做凸起门槛 | GB 55038 第 4.1.12 条：卫生间与相邻地面高差 ≤15mm，用斜坡过渡 | 支持设计意图；防水、找坡、挡水节点继续 HOLD |
| 卫生间防滑 | GB 55038 第 4.1.10 条：静摩擦系数 COF ≥0.6 | 选砖时核对产品参数 |
| 卫生间砖规格 | JGJ 367 第 4.1.6 条：用水房间"不宜"用大于 300×300 的块材 | 设计取舍：A202 的 300×600 是候选，与该建议不一致，交设计/施工方结合找坡、地漏判断 |
| 卫生间扶手 | GB 55038 第 4.1.8 条：便器和洗浴器旁应设扶手或预留安装条件 | 模型里没有扶手；主卫建议预埋 |
| 次主卫筒灯 L033 | GB 55024 第 4.6.6 条：淋浴场所 0/1 区电击防护 | 平面落在淋浴托盘投影内，安装面距完成地面 2650；是否落入 0/1 区需电气设计按分区尺寸确认，IP44 不是自动合规证明 |
| 母亲夜间起身照明 | JGJ 367 第 4.1.8 条：老人用房连接卫生间的走道"宜设灯光照明" | 现有 94 个灯位里没有床头灯和夜灯；建议加一组从床到主卫的低位感应夜灯 |
| 三级台阶 | JGJ 367 第 4.8.2、4.8.3 条：踏面防滑；老人使用的不应采用无踢面或突缘 >10mm 的踏步 | 踏面深 350，模型里已有扶手；需确认防滑条、踢面和突缘做法 |
| 门洞通行净宽 | GB 55038 第 4.1.14 条：卧室门≥0.80m、厨卫门≥0.70m（通行净宽，不是洞口宽） | 初筛：次主卧门洞 750 小于卧室门 0.80m；主卫门洞 750 扣门套后待核；H2–H4 开洞须结构许可 |
| 原有安全防护 | 原 JGJ 367 第 3.0.7 条已废止；现行依据 GB 55038 第 4.1.15、4.1.16 条（阳台栏杆、临空窗防护） | 不改动原有防护，封窗后按现行条文复核 |
| 照度 | GB/T 50034 第 5.2.1 条（推荐值，"宜"） | 没有灯具配光数据，**不判定是否达标** |
