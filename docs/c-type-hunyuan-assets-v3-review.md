## 现有方法复用

首先使用BlenderAgentStudio inspector和384px四向隔离渲染，分别导入和打开。三件大boundary数经过临时analysis-only remove-doubles1e-6归零，主要为UV分裂边，不改实际网格/UV。无degenerate/invalidvertices；不是模型力学/制造认证，也未穷尽每个内部面穿插。

材质原图中含已烘入阴影和高反射扩展。完整原纹理实际Cycles对照保留。颜色分材质首版把布套暖影误判为木材，在实际渲染中出现木斑，明确拒绝。最终沙发按底座287mm高度界线分木底座/上部linen，复用V5完整原生木和麻棉材质；边界是生成整件的结构推定，需要近景人审。床完整生成床品纹理/normal保持，降低metal/specular，避免破坏灰床头和条纹抱枕。电视柜保留生成陈设纹理。
