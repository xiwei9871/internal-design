# Task 02 — Owner Inputs Required / 业主需求清单

> 本文件为 **Task 03（布局概念）之前** 必须由业主填写的问题清单。
> 不预填任何答案；不沿用旧项目（学道街）的假设；不从户型图推断业主偏好。

填写约定：每项可答 `不知道 / 无所谓 / 具体描述`。回答后将回写为
`semantics/owner_brief.json`（Task 03 输入）。

---

## HOUSEHOLD / 住户构成

- 常住人口？（几成人/儿童/老人，年龄）
- 是否有同住老人或需无障碍考虑？
- 未来 5–10 年人口变化预期？（计划生育、老人搬入、孩子独立）

## DAILY ROUTINE / 日常作息

- 家庭成员作息是否错开？早起/晚睡对卧室分区的要求？
- 在家做饭频率？（每天 / 偶尔 / 几乎不）
- 在家办公的频率与时长？

## BEDROOM USE / 卧室用途

- 两间标注"卧室"的房间（R-BED-N 北侧 / R-BED-S 南侧）分别给谁用？
- 书房（R-STUDY）是纯办公，还是需要兼顾客房/睡眠功能？
- 主卧是否需要独立衣帽/化妆/阅读区？

## KITCHEN / 厨房

- 中式爆炒为主还是轻食为主？对封闭/开放厨房的偏好？
- 当前厨房仅能经生活阳台进入（餐厅→D-13→生活阳台→D-11→厨房），
  此动线是否接受？还是希望厨房能直接从室内进入？（涉及开门洞，
  受结构约束，需先完成现场复核）
- 需要哪些电器？（洗碗机、蒸烤箱、净水器、垃圾处理器、双门冰箱等）

## STORAGE / 收纳

- 衣物量与收纳习惯？衣帽间（R-CLOAK）是否够用？
- 有无大件物品需要存放？（行李箱、换季被褥、运动器材、婴儿车）
- 玄关是否需要鞋柜/外套柜/雨具位？

## WORK / STUDY / 工作学习

- 几人需要固定工位？是否需要隔音（视频会议/练琴）？
- 书房是否需要大量书架/设备位？

## CHILDREN / 儿童

- 有无儿童？年龄段？儿童活动/学习空间要求？
- 阳台安全防护要求？

## GUESTS / 访客

- 亲友留宿频率？是否需要客房或可转换空间？
- 聚餐/待客频率，餐厅需要多大桌位？

## LAUNDRY / 洗衣晾晒

- 洗衣机/烘干机放哪里可接受？（生活阳台是常规位，需确认上下水）
- 晾晒习惯：必须自然晾晒还是烘干机为主？阳台是否接受封闭？

## BATHROOM / 卫浴

- 两卫是否都保留？主卫是否需要浴缸？
- 干湿分离要求？智能马桶/电热毛巾架等设备需求？

## MEDIA / 影音

- 客厅电视/投影需求？是否有音响/游戏设备？
- 休闲厅（R-LEISURE）预期用途？（起居/影音/儿童活动/开放式书房？）

## SMART HOME / 智能化

- 是否需要全屋智能（灯光/窗帘/安防/空调联动）？
- 网络覆盖要求？（全屋 Wi-Fi / 有线到各房间）

## HVAC / 暖通

- 空调形式偏好？（中央空调 / 风管机 / 分体挂机）
- 是否需要地暖、新风系统？（影响层高与吊顶，与现场复核的层高数据联动）
- 现有空调机位（AC-1、东北角机位区）是否可用/够用？

## STYLE / 风格

- 风格倾向？（可参考图片，无需专业术语）
- 有无明确不喜欢的材料/颜色？

## BUDGET / 预算

- 总预算区间？是否含家电/软装？
- 预算优先投向哪里？（厨房/卫浴/收纳/材料档次）

## CONSTRUCTION SCOPE / 施工范围

- 是全屋重装还是局部改造？
- 墙体能否改动？（注意：任何墙改动前必须完成结构鉴定，
  见 field_verification_plan.md P0 项）
- 门窗是否更换？（外立面改造通常受物业限制）
- 施工期间是否需要过渡居住？

## FUTURE 5–10 YEAR NEEDS / 中长期需求

- 该房是长期自住、过渡、还是投资属性？
- 是否需要为转售/出租保留通用性？
- 有无适老化、儿童成长等可变需求？
