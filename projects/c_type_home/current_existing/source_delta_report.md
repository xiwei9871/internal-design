# Task03A RC1 — Source Delta Report

实测 DWG(`世纪欣园FF.dwg`)vs Task01 开发商图重建几何 vs 业主口述现状的差异报告。
坐标映射(已验证全部尺寸锚点):`task01 = measured + (1300, -1336)`(仅平移,无缩放)。

## RC1 规则修正(本轮)

1. **权威分工**:实测 DWG 决定**尺寸/轴网/门窗**;**墙体是否存在**以业主明确确认的当前现状为准;DWG 中与现状冲突的线稿记 `dwg_stale_geometry`,不得反过来否决业主确认。
2. **黑/白判定**:可拆性分类**只**来自原图视觉(白填/黑实/细线)逐墙人工判读 + 业主声明,**禁止**用厚度≥180/HATCH 推断不可拆。判读表内嵌于 `task03a_build_current_existing.py` 的 `VISUAL` 字典(每墙含 color_class / confidence / evidence)。
3. **冲突如实暴露**:视觉上属白类但业主确认已拆的墙 → `CLASSIFICATION_CONFLICT_TO_REVIEW`,不写成事实。
4. **北阳台**:现状 `OPEN_NOT_ENCLOSED`;未来封窗 `PROPOSED`。DWG 北缘多线 = 栏杆/女儿墙线,非封窗玻璃幕墙。
5. **错层高差**:`LEVEL_DELTA_TO_VERIFY` —— 业主口径 ≤350mm(两级踏步,第三级即平台面)与 CAD 推估 ~400mm 冲突并记,待现场量 L1→L2 完成面高差。

### 4.1 CLASSIFICATION_CONFLICT_TO_REVIEW(4 面)

`CLK-N`、`CLK-W`、`CLK-E`、`Y4500-b-CLKSEG` —— 原图判读为**白类**,但业主确认已拆除。
含义:原图白/黑画法在该户型上**不是可靠的不可拆预测**(至少衣帽间四面反例);白墙集合的有效性需业主/结构核验逐面确认。在此完成前,NO_OPEN 声明仅对 **EXTERNal envelope + 仍在场的白类内墙** 生效。

### 4.2 现存 NO-OPEN 集合(白类且在场)

- 外墙包络全体(`NO_OPEN_EXTERIOR_ENVELOPE`,与画法颜色无关)
- 白类内墙现存:X13000、STD-S、BEDN-S、Y4500-b-FOYER(黑类,见 4.3 备注)
- 待复核:Y4500-bc(AMBIGUOUS)、X7900-U(AMBIGUOUS+部分拆除)

### 4.3 注意:Y4500-b-FOYER 段判读为黑类(LOW confidence)

该段含次主卧门 D-SM。若业主规则"黑=可拆"成立,此段理论可动 —— 但它承载套房入口,功能上保留。列入复核表。
