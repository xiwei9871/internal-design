# 客餐厅木色与布艺 V5 对照测试

2026-10-10，业主指出 V4 木材偏白、纹理与参考差异明显，沙发软包的松软感、材质仍不足。保持已选 A 家具 / B 软装、餐厅跑道桌与浅色圆润吊灯，以及建筑 / 布局 / 最大包络，做受控的材质与软包修正。目标是温暖自然浅木色，不将“浅原木”解释为漂白表面。

## 调查、来源与原因

- V4 `ash_veneer` 原始扫描只有很细的均匀直纹，照片层面的纹理类型与目标不同。检查原图确认长向映射未整体转错；最初的方向判断已更正。材质库标签与原生节点不能自动保证符合选定外观。
- 新候选为 [TextureCan Wood0038](https://www.texturecan.com/details/389/)，许可 [CC0](https://www.texturecan.com/terms/)。实际下载、检查完整 4K 颜色 / 粗糙度 / OpenGL 法线 / 高度文件，并在本项目 Blender 实渲测试。它是公开程序材质，不能称厂家实物扫描。终端下载返回 406，正常浏览器下载成功，没有绕过验证或安装工具。
- 为家具从同一套贴图裁出一致的单板区域，去除地板缝；将深色底材在线性空间适配到自然浅木色，保留温和的大纹理变化。2.4×0.8 m 重复尺寸为明确的家具试验假设，供应商未给出物理尺度。数值与源文件哈希登记在 `render_config/lookdev_v5/SOURCE_REGISTER.json`，不是通用成功参数。
- 原软包零重力 / 固定整圈缝边压力原型保持规则薄平轮廓。新试验依据 Blender 5.2 官方 Cloth 与自带 Cotton 预设，使用受支撑布套、负 Shrinking Factor 增加松量、内部弹簧与压力；实际评价逐帧形变。布艺复用完整 `rough_linen` 4K 节点与图；移除旧材质 0.1 权重 / 50 mm 尺度的次表面设置，使用更自然的亚麻色。不是填充物力学认证。

## 实际试验与保留决定

1. 扩大的 Rest Shape Key 只让初始形态整体放大 / 松弛，形变很小，没有作为修正方案保留。
2. 原木纹对比与 5% 布料松量过大，形成粗重板纹和整面褶皱；候选与证据保留并拒绝。
3. 收敛木纹对比和松量后，发现 Catmull-Clark 将布套轮廓缩小，座包缝扩大到 16.6 / 19.0 mm；数值 Gate 拒绝。
4. 最终采用适中的自然木色 / 纹理，2% 布套松量，先细分再恢复记录包络。座包缝实测恢复 7.5 / 10.0 mm，底部与 z=285 mm 承托接触。保留为人工评审候选，不能声称软包已 1:1 达标。
