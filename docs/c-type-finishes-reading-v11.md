## 业主规则

- 地砖：厨房、主卫、次主卫、客卫、北阳台。北阳台保留地砖，考虑洗烘与绿植浇水。

- 普通墙面：暖白色乳胶漆；厨房、三个卫生间内侧墙面：白底浅灰暗纹瓷砖。
- 瓷砖暂定600×1200mm，细缝；以业主附件图3为纹理、图4为铺贴效果参考。尚未选择厂商、SKU、防滑等级；此版为外观确认模型，不作为采购或防水施工规格。

## 原因与处理

旧版 `PRESENTATION_TILE_service_balcony` 及 `PRESENTATION_TILE_north_sunroom` 是旧的地砖展示覆盖面。走廊及卧室虽标为木地板，却沿用与客厅不同、木纹弱且偏白的 `RENDER_PALE_WOOD_FLOOR`。现统一至 `V11_UNIFIED_PALE_ASH_FLOOR`。北阳台按最新意见保留瓷砖。

复用项目已使用的白蜡木贴图与1200×180mm错缝方法，将颜色和拼接合并为小幅可携带贴图；厨房及卫生间沿现有墙面多边形裁切出饰面薄层，继承真实门窗洞口，未凭效果图新建墙体或填洞。原墙、楼板、家具网格不变。

## 书架与重复长凳

- 书柜、3层搁板、侧立柱和书本整组99对象放在业主点选墙西面。
- 按门框以北至墙北端的可用墙段居中：柜体中心Y=5673mm，南北各留约424mm。
- 柜底绝对标高450.5mm，结构完成面450mm；0.5mm仅为渲染防重叠偏移，视觉落地。不再沿用旧版505mm悬挂高度。
- 维持820mm宽、320mm深及原家具材质；柜体与既有台阶的实际轮廓水平距离约1424–1900mm，非宽泛AABB估算。
- 对既有卧室门叶0/30/60/90度采样与新柜体整组做网格碰撞检查。安装时仍应按实物及现场门扇包络复核。
- `READING_3205A_PADDED_BENCH` 是旧阅读角遗留长凳，先前已因与电视低柜重叠而隐藏，后续版本又出现。此次恢复隐藏，保留原网格，不改电视柜。
